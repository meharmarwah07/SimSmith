## World-frame conventions

- World frame is the scene's root frame (body `world`, id 0); all positions below are in this frame, metres, right-handed, **z-up** (gravity is [0.0, 0.0, -9.81] m/s^2, i.e. -z).
- The robot base (body `link0`) sits at the world origin (pos=[0.0, 0.0, 0.0], no rotation) -- world coordinates ARE base coordinates for this robot.
- The ground/table surface is the `floor` plane geom at world z=0 (`<geom name="floor" type="plane" .../>` in the included scene file). There is no separate table body/geom; the floor plane is the support surface the robot rests on.

## Where get_task() values apply

- `get_task("reach")["target_pos"]` is a free-standing world-frame point -- **there is no body, geom, site, or any other scene element for it**. It exists only as a number the script reads and the verifier independently recomputes from the seed; nothing in the XML represents it visually or physically.
- Success compares this point only to the measured `ee_pos` (the `hand` body's position); the target is never something a script spawns in the scene.
