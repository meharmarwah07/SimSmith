# MuJoCo API reference (pinned: mujoco 3.15.0)

Generated by scripts/gen_mujoco_api_doc.py via introspection -- signatures and
docstrings only, extracted from the actually-installed module, not hand-typed.
Reference material, not a worked solution.

Covers the calls needed to drive a Franka Panda arm and gripper through a reach or pick_place task in MuJoCo: loading a model (MjModel, MjData), stepping the simulation forward in time (mj_step), forward kinematics (mj_forward, mj_kinematics, mj_comPos), Jacobians for IK on the arm (mj_jac, mj_jacBody, mj_jacSite), looking up a body/joint/site by name (mj_name2id, mj_id2name), and resetting the arm/gripper/cube state (mj_resetData, mj_resetDataKeyframe).
